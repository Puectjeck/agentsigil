How it works

  • AgentSigil is an ERC-721 contract on BNB Smart Chain. It checks whether your wallet holds a SPACE ID Agent ID (a name.ai identity) by calling balanceOf on the Agent ID contract 0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F. No Agent ID, no claim — the check happens on-chain, inside the claim transaction itself.
  • One claim per wallet per UTC day. Claiming on consecutive days builds your streak; missing a day resets the streak to 1 on your next claim.
  • Each claim mints one sigil NFT to your wallet. The artwork is an SVG generated and stored entirely on-chain, showing your streak, total claims, and the UTC day.
  • Sigils are soulbound: they cannot be transferred, sold, or approved to anyone. They are a record of showing up — nothing more.
  • Claiming is free. You only pay the BNB Smart Chain network fee (gas) for your own transaction, which you review and confirm in your own wallet.
  • You connect your own wallet in your own browser and confirm every transaction yourself. This page never asks for a seed phrase, private key, or pairing code, and there is no QR-code sign-in.
  • Don't have an Agent ID yet? Per Binance Wallet's instructions, an Agent ID can only be claimed inside the Binance App: Wallet > homepage banner > Agent ID.

Contract & owner permissions

  • Contract address: to be filled after deployment
  • The contract's owner is set once, in the constructor, to a dedicated wallet address (it is not the account that deployed the contract — the deployer holds no power after deployment).
  • The owner's only powers are pause() and unpause() — a safety switch that can stop and resume claims. The owner cannot mint, cannot move or withdraw anything (the contract holds no funds), cannot change the Agent ID gate, and cannot transfer ownership. There is no proxy and no upgrade mechanism. The full source code is public and verified on BscScan.
  • A sigil has no promised value and this page makes no promise of any reward. It is a daily on-chain keepsake for Agent ID holders.
